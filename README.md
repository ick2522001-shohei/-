## 初回設定とデプロイ

初回のみ、GitHubリポジトリの「Settings」→「Pages」→「Build and deployment」で、Sourceを「GitHub Actions」に設定してください。

設定後は、`main` ブランチへの push をきっかけにGitHub Actionsが自動でデプロイします。手動で実行する場合は、「Actions」から「Deploy to GitHub Pages」を実行してください。
